# 学生-教师-课程-成绩表

## 一、整体表关系说明
1. Student（学生表）：基础学生信息
2. Teacher（教师表）：基础教师信息
3. Course（课程表）：课程基础信息
4. SC（选课成绩表）：关联表，连接学生、教师、课程，存储选课与成绩状态
5. 关联关系：SC 表通过外键分别关联 Student、Teacher、Course 三张主表

---

## 二、数据表详细结构
### 1. 学生表（Student）
**表用途**：存储学生基本信息
| 字段名 | 数据类型 | 非空约束 | 主键/外键 | 字段说明 |
|--------|----------|----------|-----------|----------|
| sid | INT | 是 | 主键 | 学生唯一编号 |
| name | VARCHAR(100) | 是 | - | 学生姓名 |
| birth | DATE | 否 | - | 出生日期 |
| gender | VARCHAR(10) | 否 | - | 性别 |

**约束**：以 sid 作为唯一主键，确保学生编号不重复。

---

### 2. 教师表（Teacher）
**表用途**：存储教师基本信息
| 字段名 | 数据类型 | 非空约束 | 主键/外键 | 字段说明 |
|--------|----------|----------|-----------|----------|
| tid | INT | 是 | 主键 | 教师唯一编号 |
| name | VARCHAR(100) | 是 | - | 教师姓名 |
| gender | VARCHAR(10) | 否 | - | 性别 |

**约束**：以 tid 作为唯一主键，确保教师编号不重复。

---

### 3. 课程表（Course）
**表用途**：存储课程基础信息与评分规则
| 字段名 | 数据类型 | 非空约束 | 主键/外键 | 字段说明 |
|--------|----------|----------|-----------|----------|
| courseNumber | INT | 是 | 主键 | 课程唯一编号 |
| courseName | VARCHAR(100) | 是 | - | 课程名称 |
| credit | INT | 否 | - | 学分 |
| courseHour | INT | 否 | - | 课时 |
| ScoreType | ENUM | 否 | - | 评分类型 |

**枚举值说明**：
ScoreType：percentile(百分制)、fivePoint(五分制)、examCheck(考查)

**约束**：以 courseNumber 作为唯一主键，确保课程编号不重复。

---

### 4. 选课成绩表（SC）
**表用途**：核心关联表，记录学生选课、授课教师、成绩及状态
| 字段名 | 数据类型 | 非空约束 | 主键/外键 | 字段说明 |
|--------|----------|----------|-----------|----------|
| sid | INT | 是 | 联合主键+外键 | 关联学生表学生编号 |
| tid | INT | 是 | 联合主键+外键 | 关联教师表教师编号 |
| courseNumber | INT | 是 | 联合主键+外键 | 关联课程表课程编号 |
| RealScore | INT | 否 | - | 实际得分 |
| status | ENUM | 是 | - | 成绩状态 |

**主键约束**：sid + tid + courseNumber 联合主键，保证同一学生、同一教师、同一课程的记录唯一。

**外键约束**：
- sid 引用 Student(sid)
- tid 引用 Teacher(tid)
- courseNumber 引用 Course(courseNumber)

**枚举值说明**：
status：pending(待提交)、submitted(已提交)、confirmed(已确认)、finished(已完成)、exception(异常)
